# Biloo Nature Match Redesign

## Product direction

Biloo Nature Match is a calm, colorful sorting and pattern game for young children. The game uses only friendly animals, leaves, flowers, mushrooms, trees, fruit, and other nature symbols as playable pieces and rewards.

## Experience principles

- Every visible color is named with a descriptive real-world color name.
- Feedback is positive-only: gentle bounce, leaf particles, soft sound, and optional vibration.
- Progress is represented by a growing tree and an expanding nature gallery rather than a numeric IQ score.
- The interface remains free of ads, purchases, lives, leaderboards, and social comparison.
- Settings and exits remain behind a parent gate.
- Motion should feel smooth and soft, and must respect reduced-motion preferences.

## Navigation

The in-game hamburger menu contains:

- Play / New Game
- Levels
- Settings
- Nature Gallery
- Credits

## Collection system

Each completed level unlocks a named animal or plant collectible. Every four completed levels advances the central tree through seedling, young tree, flowering tree, and great forest tree stages. Seasons shift with progress from spring to summer, autumn, and winter meadow styling.
