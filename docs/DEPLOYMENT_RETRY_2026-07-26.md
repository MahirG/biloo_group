# Biloo Group production deployment retry

Deploy the current `MahirG/biloo_group` `main` branch to the existing `biloo-group` Vercel project. This production target serves the Biloo Group website and its public product hubs while keeping `apps/erp` and `apps/mezgeb` as independently deployed applications.

Do not use the Biloo Group root project to replace either product application's dedicated production deployment.
